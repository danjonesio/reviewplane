What the hot-reload figure includes
-----------------------------------
  It is wall-clock from the edit landing on the development machine to the
  updated text being visible in central Chromium, which is what a user
  experiences. It therefore includes the file watcher (polling every 200ms),
  the bundler, the update WebSocket through the tunnel, the browser applying
  the module, and the control-plane round trip that observes it. It is not a
  measurement of the tunnel alone, and it MUST NOT be read as one.
